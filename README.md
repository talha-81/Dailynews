# Dailynews

Talha's twice-daily news briefings (morning ☀️ and evening 🌙 editions, PKT), published with GitHub Pages.

- Archive: https://talha-81.github.io/Dailynews/
- Pages: `briefings/YYYY-MM-DD-am|pm.html`

`index.html` is regenerated automatically on every publish (newest first). `.nojekyll` makes Pages serve files as-is.
